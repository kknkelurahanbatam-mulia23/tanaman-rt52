# Tanaman RT 52

Website statis informasi 20 tanaman untuk GitHub Pages.

## Alamat yang digunakan QR

`https://2313070-luthfiyahya.github.io/tanaman-rt54/`

PENTING: gunakan nama repository **tanaman-rt54** persis seperti ini. Jika nama repository atau username berubah, QR harus dibuat ulang.

## Publikasi

1. Buat repository public bernama `tanaman-rt54`.
2. Upload seluruh isi folder ini ke root repository.
3. Buka Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main dan folder /(root), lalu Save.
6. Tunggu hingga alamat `https://2313070-luthfiyahya.github.io/tanaman-rt54/` aktif.

Setelah aktif, QR pada folder `qr` akan membuka halaman informasi masing-masing tanaman.
